# 神戸マツダ ぐるっと点検ネット 🚗

兵庫県内の **神戸マツダ複数店舗** をネットワークでつなぎ、車検・点検を
「めんどうなこと」から **「おでかけのついで」** に変えるための予約・運用プラットフォーム（コンセプトデモ）。

## 🎯 解決したい課題

- お客様は「出かける前に済ませたい」ため、**予約が午前に集中**し、**午後がぽっかり空く**。
- 複数店舗を持つ強みが、予約・スタッフ運用に活かしきれていない。

## 💡 提供する価値

| # | 仕組み | 概要 |
|---|--------|------|
| 1 | **お出かけ先で点検** | 目的地のエリアを選ぶと、近くて空いている店舗をAIがおすすめ順に提案。姫路の人が神戸へ行く日は神戸店で、神戸の人が姫路へ行く日は姫路店で点検できる。 |
| 2 | **午後への誘導** | 午前偏重を是正するため、午後の空き枠を可視化し「待ち時間が少ない」と訴求。 |
| 3 | **入庫スケジュールの可視化** | 全店舗のAM/PM稼働率・スタッフ数をヒートマップで一目把握。 |
| 4 | **スタッフの店舗間配置** | 神戸店が空いている日は明石店へ応援。AIが需要と人員の過不足を検知して応援を提案。 |
| 5 | **AI最適化アシスタント** | 午後誘導・店舗振り分け・応援配置を重要度つきで自動提案。 |
| 6 | **おでかけ情報ページ** | 各店舗周辺のグルメ・観光・遊びスポットを楽しく紹介。 |

## 🗺️ 画面構成（お客様向け／スタッフ向けを分離）

お客様向けと店舗・本部スタッフ向けで、**ナビゲーションも見た目も独立**しています。
Next.js の Route Group（`(customer)` / `(staff)`）で別レイアウト・別ヘッダーを持たせています。

### 🧑‍🤝‍🧑 お客様サイト（明るい白基調のヘッダー）
- `/` … ランディング（課題と仕組みの紹介、ネットワーク全体の稼働サマリー）
- `/availability` … **空き店舗をさがす**。エリア・日付・点検内容を選ぶと、AIがおすすめ順に空き店舗を提示。
- `/stores` … 店舗一覧 ＋ おでかけスポット
- `/stores/[id]` … 店舗詳細。近隣のグルメ・観光・遊びスポット ＋ 直近の空き状況 ＋ スタッフ体制。

### 🛠️ スタッフ管理ポータル（ダークな業務用ヘッダー）
- `/staff` … 入庫スケジュール ダッシュボード（店舗×日付の稼働ヒートマップ、本日の店舗別状況）
- `/staff/members` … スタッフ店舗間配置（所属／応援可能、AI応援提案、スタッフ名簿）
- `/staff/ai` … AI最適化アシスタント（提案のフィルタリングとネットワーク診断）

> お客様ヘッダーには控えめな「スタッフの方 →」リンク、スタッフヘッダーには
> 「← お客様ページ」リンクを配置し、相互に行き来できます。

## 🤖 AI最適化エンジン

`src/lib/optimizer.ts` にルールベースの最適化ロジックを実装。

- **店舗レコメンド** … 目的地との近さ・午後の空き・全体の空き・スタッフ充足度をスコアリング。
- **午後誘導の提案** … 午前稼働 ≥ 85% かつ 午後稼働 ≤ 45% の日を検出。
- **近隣店舗への振り分け** … 逼迫店舗の25km圏内に余裕のある店舗があれば案内。
- **スタッフ応援配置** … 入庫予定に対し人員不足の店舗へ、応援可能な近隣スタッフを提案。

> 実運用では、予約実績・天候・キャンペーン情報などを学習し、
> LLM（Claude等）による自然言語提案・自動配信へ拡張する想定です。

## 🏗️ 技術スタック

- **Next.js 16**（App Router）/ **React 19** / **TypeScript**
- **Tailwind CSS v4**
- データは `src/lib/` の決定論的シードで生成（DB不要・再現性あり）

```
src/
├── app/                 # ページ（App Router）
│   ├── layout.tsx             # ルート（html/body/フォント）
│   ├── (customer)/            # ── お客様サイト（独立レイアウト）
│   │   ├── layout.tsx               # CustomerHeader + フッター
│   │   ├── page.tsx                 # ホーム
│   │   ├── availability/            # 空き店舗をさがす
│   │   └── stores/                  # 店舗一覧・詳細
│   └── (staff)/               # ── スタッフ管理ポータル（独立レイアウト）
│       ├── layout.tsx               # StaffHeader + フッター
│       └── staff/                   # /staff, /staff/members, /staff/ai
├── components/          # 共通UI（CustomerHeader / StaffHeader / カード等）
└── lib/                 # ドメインロジック
    ├── types.ts               # 型定義
    ├── stores.ts              # 店舗マスタ＋サービス＋距離計算
    ├── staff.ts               # スタッフマスタ（店舗間応援関係）
    ├── schedule.ts            # 入庫枠・稼働の生成（午前偏重を再現）
    └── optimizer.ts           # AI最適化エンジン
```
